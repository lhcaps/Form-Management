## 6. CRITICAL INVARIANTS

These invariants are enforced by the current code (verified by reading the source). Cursor did not modify them; this audit does not claim credit for them.

1. **LIFECYCLE_BOUNDARY** — Runtime template render (`/forms/runtime/*`) cannot use persisted document render intent (`GENERATED_*`), and vice versa. Enforced by `assertRenderIntentBoundary` in `api-render-boundary.policy.ts` (RUNTIME_INTENTS = {RUNTIME_PREVIEW_SESSION, RUNTIME_DIRECT_DOCX}; GENERATED_INTENTS = {GENERATED_RENDER_DOCX, GENERATED_SAVE_CONTRACT_INPUTS, GENERATED_SAVE_LEGACY_INPUTS, GENERATED_BM031_DIRECT_SAVE}).

2. **SESSION_PERSISTED_FALSE** — Runtime preview-session response always sets `persisted: false` and is asserted by the client (`runtime-template-preview.ts` line 110). No DB row created for the session.

3. **NO_GENERATED_DOCUMENT_ID** — Standalone template route has zero `generatedDocumentId` references in workspace state, component props, or session metadata. The workspace has no `/documents/:id` navigation (only one link to `/documents` list at line 795).

4. **NO_HISTORY_LINK** — Standalone route has no "Lịch sử xử lý" / `/history` link.

5. **CONTENT_TYPE_GUARDS** — Client guards Content-Type on session creation (must be `application/json`), DOCX download (must be DOCX), and PDF fetch (must be `application/pdf`). Defense against regression in which backend returns binary instead of JSON.

6. **TEMPLATE_CODE_VALIDATION** — `normalizeStandaloneTemplateCode` requires `/^BM-\d{3}$/`. Rejects path traversal, arbitrary input.

7. **SESSION_ID_VALIDATION** — `SESSION_ID_PATTERN = /^runtime_preview_[a-f0-9-]{36}$/u` strict UUID format. `sanitizeSessionId` rejects malformed IDs.

8. **SESSION_TTL** — 60 minutes (`SESSION_TTL_MS = 60 * 60 * 1000`). `cleanupExpiredSessions()` runs on every new session creation.

9. **PATH_TRAVERSAL_GUARD** — `isPathInside(pdfPath, sessionDir)` rejects PDFs outside the session directory.
