## Source of Truth (SOT) Policy

Understanding what each artifact type means is critical for maintaining data integrity.

### SOT Hierarchy

| Artifact | Type | Location | Notes |
|---|---|---|---|
| **normalized DOCX** | Structural SOT | `storage/templates/normalized-docx/{BM-XXX}/{BM-XXX}_normalized.docx` | The authoritative template file. Runtime renders from here directly. |
| **locked contract JSON** | Semantic SOT | `docs/audit/docx/contracts/locked/*.contract.locked.json` | Current working semantic definition. Slots, fields, bindings. |
| **compiled-v2** | Derived artifact | `docs/audit/docx/compiled-v2/*.compiled.json` | Generated from locked contracts. NOT SOT — can be stale. |
| **DB `compiled_json`** | Runtime copy | MariaDB `form_contract_versions` table | Published copy. NOT SOT. |

### Critical Rule

> **Render PASS proves executable render fidelity only. Render PASS does NOT prove semantic correctness.**

A template can render successfully with wrong bindings (the `formData` fallback fills unbound placeholders with raw values silently). The locked contract semantic definitions must be independently verified.

## Archiving Strategy

When a remediation phase closes:

1. Move the output folder to `docs/audit/_archive/{phase-name}/`
2. Update any hardcoded paths in scripts (see `path-dependency-report.latest.md`)
3. Add `docs/audit/_archive/` to `.gitignore` (optional, once stable)

**Do NOT add `docs/audit/docx/`, `docs/audit/form-authoring-baselines/`, or any active gate output to `.gitignore`.**

- **Do NOT compile** `packages/form-contracts` unless locked contracts are confirmed correct
- **Do NOT publish to DB** unless C3 gate shows 0 critical/stale issues
- **Do NOT commit** if `pnpm audit:contract-sync` exits non-zero
- **Do NOT delete** `docs/audit/docx/contracts/locked/` — losing these loses the semantic SOT
- **Do NOT mutate** locked contracts without a decision ledger
