Generated by review against the Human Authoring Packet, Legal Review Packet, Accepted Non-Rendered Metadata Packet, and the uploaded official TT 03/2026 template ZIP.

## Global rules

1. De-duplicate audit rows by `(BM, placeholder)`. Most rows appear twice because the audit emits both `CONTRACT_SLOT_WITHOUT_TEMPLATE_PLACEHOLDER` and `BINDING_WITHOUT_TEMPLATE_PLACEHOLDER` for the same field.
2. Do not blindly insert near generic anchors such as `…`, `(none)`, or misleading anchors like date lines. Open the source template and place the placeholder at the official numbered blank.
3. If a compound line already renders the value, do not add the atomic child field as another visible placeholder.
4. If the template already contains a suffixed variant such as `document.fullDocumentCode4`, `document.fullDocumentCode6`, or `document.fullDocumentCode8`, prefer canonical alias/rename/refactor over rendering duplicate placeholders.
5. After edits: run structure extraction, normalization, locked verification, and visual render QA.
