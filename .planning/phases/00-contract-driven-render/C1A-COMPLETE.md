## Technical Notes

### Why Windows execution?

VM Linux không thể chạy compile script vì:
- Không có `pnpm` command
- `node_modules` symlinks bị broken (pnpm workspace structure)
- Dependencies missing (zod, esbuild, tsx)
- Network restricted (npm 403)

→ **Solution**: Chạy trên Windows host nơi có full dependencies.

Mỗi `.compiled.json` file chứa:
